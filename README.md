Chihuahua vs. Muffin Classifier 🐶🧁
🏆 3rd Place Winner - 24-Hour AI Hackathon!

What is this project?
This is a smart computer program. It looks at a picture and guesses if it is a Chihuahua dog or a yummy blueberry muffin.

How did we build it?
We built this in a very fast 24-hour hackathon with a team of 3 people.

We used a computer brain called ResNet-18.

We used a tool called 3LC to clean up trick pictures (like blurry photos or dog toys).

By cleaning the data, we made the computer guess the right answer almost perfectly!
